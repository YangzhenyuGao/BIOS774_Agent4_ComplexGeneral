Semi-Supervised Five-Encoder Shared-Private Product-of-Experts VIB

Each patient is represented by five foundation-model mean embeddings whitened inside training folds using labelled and unlabelled H&E cohorts. A semi-supervised Shared-Private Product-of-Experts Variational Information Bottleneck infers a consensus latent posterior across encoders while routing encoder-specific technical artifacts into orthogonal private latents via masked cross-view decoding. A logit-adjusted cosine classifier with inner-fold temperature scaling and macro-F1 threshold tuning predicts PAM50 subtypes. Repeated nested patient-level and 19-site-held-out cross-validation against null and linear baselines establishes broad, partial, site-confounded, or insufficient predictability.

Rationale: Five encoders create 7,424 features for 802 patients alongside strong site confounding and 8.1% Her2 prevalence. Semi-supervised Product-of-Experts inference extracts cross-encoder morphological consensus while orthogonal private latents absorb scanner-specific artifacts without using site labels. Logit-adjusted cosine classification with inner-fold calibration protects minority recall and log-loss.
